# Priya Sharma | Women's Leadership Coach

An executive coaching and leadership acceleration web application for female Senior Managers, Directors, and emerging Vice Presidents ready to break the director-to-VP ceiling and lead with unshakeable boardroom authority.

Built with **React 18**, **Tailwind CSS**, **Vite**, **Framer Motion**, and **Lucide React**.

---

## ✨ Features

- **Executive Single-Page Experience**: Instant, fluid routing between **Home**, **About Priya**, **Services & Programs**, and **Contact & Booking**.
- **Interactive Calendly-Style Booking Widget**:
  - Live calendar month matrix with active day selection.
  - Interactive time slots (9:00 AM, 10:30 AM, 1:00 PM, 2:30 PM, 4:00 PM).
  - Timezone selector (EST, CST, PST, GMT, CET, IST).
  - 2-Step executive intake questionnaire (role, company, primary career hurdle, 6-month vision).
  - Instant confirmation screen with Zoom call simulation and toast notifications.
- **Universal Discovery Call Modal**: Accessible from any *"Book a Free Discovery Call"* button across every page.
- **Challenges I Solve**: The Promotion Paradox, Executive Visibility & Boardroom Authority, and Managing High-Stakes Teams.
- **Signature Program**: The Ascend Executive Accelerator™ (12-Week Immersion) with interactive module breakdowns.
- **Testimonials with Metrics**: Real client outcomes (+38% comp raise, VP promotion, 16 hrs/week saved).
- **3 Transparent Investment Tiers**: 1:1 Executive Advisory ($3,500), The Ascend Accelerator ($1,850), and Corporate Intensives (From $6,000).
- **Corporate Keynotes & Workshops**: Interactive B2B inquiry form for enterprise ERGs and summits.
- **Lead Magnet**: "The Executive Visibility Playbook" (5 scripts to command the room) with instant simulated download.
- **Interactive FAQ Accordion**: Addresses corporate L&D budget reimbursement, time commitment, and ROI.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or pnpm

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

### 4. Preview Production Build Locally
```bash
npm run preview
```

## 🌐 Deployment

### Deploy to Vercel
1. Push this repository to GitHub / GitLab / Bitbucket.
2. Import the project in [Vercel](https://vercel.com).
3. Framework Preset: **Vite**.
4. Click **Deploy**. (The included `vercel.json` automatically configures SPA routing rewrites).

### Deploy to Netlify
1. Connect your repository to [Netlify](https://netlify.com).
2. Build command: `npm run build`
3. Publish directory: `dist`
4. The included `public/_redirects` file handles clean SPA routing.
